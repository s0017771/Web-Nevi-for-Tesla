# 🗡️ 리듬 세이버 (vr-saber.html) — 작업 지침

> 먼저 `HANDOFF/CONTEXT.md`. 가장 성숙한 게임. 뮤직랩 ABC 곡을 피아노 샘플로 연주하며 베는 리듬 게임 + 드럼 모드 + 드럼 레슨.

## 현재 상태(성숙)
- **ABC 파서 내장**: 표준 ABC(L/Q/M/K, 음표/옥타브/임시표/길이/쉼표/마디/화음/반복 `|: :|`/중간 조·템포 변경 `[K:][Q:]`). 다성부에서 멜로디(V:1)·베이스(V:2bottom) 추출. `__SABER_TEST__.parseABC`.
- **곡 3개**: `songs/*.abc` → `vr-songs.js`(`window.SABER_SONGS`) 자동 생성. (퇴근길의 반딧불 리믹스/어제에게 풀버전/바흐 미뉴에트)
- **사운드**: 멜로디·베이스 = **FluidR3_GM 피아노 샘플**(폴백 오실레이터 피아노), 드럼 = **FluidR3_GM percussion 샘플**(폴백 합성). 사양서 리버브(tail1.6/decay2.8/wet0.22)+컴프(−16/12/2.5/10ms/250ms). `renderOffline`로 오프라인 오디오 검증(음정 100%·클리핑0 확인됨).
- **큐브가 박자에 도착**: 노트가 울릴 시각에 큐브가 도착하도록 리드타임 앞서 생성(비트세이버식). 음높이→큐브 높낮이(로그).
- **3가지 모드**(시작 메뉴 토글): 🎵 멜로디 치기 / 🥁 드럼 치기 / 🎓 드럼 레슨.
  - 멜로디: 색 맞춰 베기(빨강=오른손/파랑=왼손).
  - 드럼 치기: 큐브=드럼 타격(스네어·오픈햇·탐), **킥·하이햇은 자동**(퀘스트 발 추적 불가 대응).
  - 드럼 레슨: 👂듣기/⏸기다려주기/▶안기다려주기 (기법 익히기).
- **드럼 기법 8종** + **곡마다 비트 자동 추천**(악보 R:/M:로: Dance→디스코, Ballad→발라드, 3/4→왈츠).
- **기본 10단계 모드**(계이름 멜로디) 유지. 모바일 탭=블록 베기(`__vrTapAt`).
- 테스트: `__SABER_TEST__`(renderOffline, startSong, startLesson, setKit/setTarget 등). 스크래치 테스트 다수.

## 가능한 다음 작업(사용자와 상의)
- 곡 추가(`.abc`를 `songs/`에 넣고 `vr-songs.js` 재생성: node 스크립트로 T:제목·본문 임베드).
- 악기 선택(사양서 GM 프로그램: 48현악/40바이올린/42첼로/73플루트/71클라리넷), 리버브 깊이(살짝/보통/깊게) 토글.
- 레슨: 템포 조절·한 소절 반복·정확도 점수·메트로놈.
- 난이도/채점 밸런스, 손맛(파티클/햅틱) 강화.
- 주의: `__SABER_TEST__.renderOffline`과 `stepAudio`는 같은 synth 경로를 공유하도록 유지(검증=실제 소리).

## 파일
