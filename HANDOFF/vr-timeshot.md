# ⏱️ 시간정지 슈터 (vr-timeshot.html) — 작업 지침

> 먼저 `HANDOFF/CONTEXT.md`. 내가 움직일 때만 시간이 흐르는 액션(슈퍼핫 느낌, 오리지널). 총알을 피하고 적을 처치.

## 현재 상태 (~70% — 사운드/그래픽 집중 패스 완료)
- `motion-time`: 이동량으로 `window.__timeScale` 산출 → 적/총알 속도 + 사운드 긴장도(`SND.setTension`)가 반응.
- **GFX 모듈(인라인)**: 캔버스 반실사 텍스처 생성기 — 그림자 총잡이 스프라이트(4색 변형+피격플래시), 황혼 하늘, 젖은 콘크리트 바닥, 머즐플래시/임팩트/트레이서/레티클. 각 data URL 캐싱, 실패 시 1x1 투명 폴백.
  - 적은 이제 박스가 아니라 **빌보드 a-image 스프라이트**. data URL은 `src`를 `material`보다 **나중에** 설정(안 그러면 material.src가 지워짐).
  - **총알 트레이서는 속도 방향 정렬**(`bullet.orient` = stretched billboard: 긴 축=진행방향, 노멀은 카메라 쪽). billboard는 쓰지 않음.
- **오디오 언락**: 모바일은 AudioContext가 사용자 제스처에서 시작돼야 함 → 첫 입력(pointerdown/touch/click/key)에서 `SND.resume()` 보장. VR 입장 버튼은 CSS로 우상단 이동(발사 버튼과 겹침 방지).
- **SND 모듈(인라인)**: 리얼 Web Audio SFX — 총성/임팩트/피격/휘익은 **필터 노이즈+바디+빠른 엔벨로프**로 합성(생 비프음 없음). 리버브 IR `(1-t)^2.8` tail1.6s wet0.22 + 마스터 컴프(−16/knee12/ratio2.5)+makeup0.9 (사양서). 적응형 앰비언스+듀얼심박. `renderOffline(name,sec)`로 헤드리스 오디오 검증.
- **시간정지 연출**: `timetint` 컴포넌트가 카메라 앞 블루 틴트 투명도를 timeScale로 조절(멈추면 짙어짐) + 씬 fog.
- **난이도 웨이브**: `window.__diff`(초당 `rampDiff`로 적수/스폰속도/발사속도 상승).
- **모바일 조작(중요)**: 화면 방향패드(앞/뒤/좌/우)로 `#rig`를 카메라 기준 이동 → 카메라 월드좌표가 변해 **시간이 흐르고 총알을 회피**(모바일 핵심 해결). `● 발사`·`⟳ 정면(중앙정렬)` 버튼. 카메라 `look-controls="touchEnabled:false"`로 **스와이프 화면회전 비활성**(자이로 조준은 유지), 정면 버튼으로 재정렬. 빈 곳 탭/적 탭 사격도 유지(패드/버튼 조작 직후 500ms는 오발사 억제). `window.__MOBILE_TEST__` 훅.
- 모바일 탭 사격: `window.__vrTapAt` → 카메라 정면으로 `__playerShoot`.
- VR에선 날아가는 총알로만 적 처치(클릭 처치는 데스크톱 전용 가드 유지).
- 테스트: `tests/timeshot.e2e.mjs` (A-Frame abort + OfflineAudio + 모바일 터치 컨텍스트). 로직·오디오·웨이브·탭·스프라이트·모바일 배선 39개 통과.

## 기기(퀘스트/폰)에서 사용자 확인 필요 — 코드로 검증 불가
- A-Frame 렌더: 스프라이트/하늘/바닥/틴트가 실제로 보이는지, 적 빌보드 방향, 틴트 깊이감.
- 소리: 실제 스피커/헤드폰에서 총성이 "기계음 아닌 리얼"하게 들리는지, 앰비언스 볼륨(휘익은 0.08→0.20으로 키움).
- **모바일 플레이감**: 방향패드 이동 속도(현재 2.6 m/s), 이동으로 시간이 자연스럽게 흐르는지, 정면 버튼 재정렬, 자이로 조준.
- 밸런스: 난이도 상승 곡선, 적 사거리/발사빈도.

## 남은 폴리시(70%+ 이후, 사소)
- 하늘 haze 밴드 경계 부드럽게, 피격 플래시 강도 완화, 적 이동 중 발이 바닥에 붙는 느낌(y 고정).
