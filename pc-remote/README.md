# 브로가드 PC 리모컨

폰/태블릿에서 **같은 와이파이**에 연결된 **Windows PC**를 조종하는 리모컨입니다.
브라우저만 있으면 되고(폰에 앱 설치 X), PC에서 작은 파이썬 프로그램 하나만 실행하면 됩니다.

> 단계별로 만들고 있어요.
> - **1단계 (지금): 화면 미러링** — 폰에서 PC 화면을 실시간으로 보기 (보기 전용)
> - 2단계: 마우스 (탭=클릭, 드래그, 스크롤, 우클릭)
> - 3단계: 키보드 (한글 타이핑, 단축키, 볼륨/발표 키)

---

## 1단계 — 화면 미러링 사용법 (Windows)

### 1. 준비물
- PC와 폰이 **같은 와이파이**에 연결되어 있어야 합니다.
- PC에 **Python**이 설치되어 있어야 합니다. (`python --version` 으로 확인)

### 2. 라이브러리 설치 (PC에서 한 번만)
명령 프롬프트(cmd) 또는 PowerShell에서:
```
pip install mss pillow
```

### 3. 실행 (PC에서)
`pc_remote.py` 가 있는 폴더에서:
```
python pc_remote.py
```
실행하면 이런 화면이 나와요:
```
======================================================
  브로가드 PC 리모컨 · 1단계 화면 미러링
======================================================
  폰/태블릿 브라우저에서 아래 주소를 여세요:
      http://192.168.0.12:8787
  PIN:  3741
  화면: 1920 x 1080
======================================================
```
- 처음 실행하면 **Windows 방화벽 창**이 뜰 수 있어요 → **"액세스 허용"**(개인 네트워크 체크)을 눌러주세요. 안 그러면 폰이 접속하지 못합니다.

### 4. 폰에서 접속
1. 폰 브라우저(크롬/사파리 등) 주소창에 위에 표시된 주소를 입력: 예) `http://192.168.0.12:8787`
2. PC 화면에 표시된 **PIN**(예: 3741)을 입력 → **접속**
3. PC 화면이 실시간으로 보입니다. 가로로 더 크게 보려면 폰을 가로로 돌리거나 **전체화면** 버튼을 누르세요.

### 버튼
- **화질**: 낮음 / 보통 / 높음 (느리면 '낮음'으로)
- **다시 연결**: 화면이 멈추면 누르기
- **전체화면**: 폰 화면 꽉 채우기

### 종료
PC 터미널에서 **Ctrl + C**.

## 자주 겪는 문제
| 증상 | 해결 |
|---|---|
| 폰에서 주소를 열어도 안 열림 | PC·폰이 **같은 와이파이**인지 확인. 방화벽에서 **액세스 허용**했는지 확인. |
| "PIN이 틀렸거나 연결 안 됨" | PC 터미널의 PIN을 다시 확인. 주소의 포트(:8787)까지 정확히. |
| 화면이 느리거나 끊김 | **화질 '낮음'**, 또는 실행 시 `python pc_remote.py --fps 8` |
| 포트가 이미 쓰임 | `python pc_remote.py --port 9000` 처럼 다른 포트로 |

## 실행 옵션
```
python pc_remote.py --port 9000     # 포트 변경 (기본 8787)
python pc_remote.py --pin 2580      # PIN 직접 지정
python pc_remote.py --no-pin        # PIN 없이 (집 네트워크 신뢰 시)
python pc_remote.py --fps 15        # 초당 프레임 (기본 12)
python pc_remote.py --demo          # 가짜 화면 (설치 없이 테스트)
```

## 보안 메모
- **같은 와이파이 안에서만** 접속되도록 만들었습니다. 공용/회사 와이파이에서는 PIN을 꼭 쓰고, 끝나면 창을 닫으세요.
- 집 밖에서 쓰고 싶다면(2번 단계), 나중에 Tailscale 같은 걸로 안전하게 확장할 수 있어요.
