# 브로가드 PC 리모컨

폰/태블릿에서 **같은 와이파이**에 연결된 **Windows PC**를 다루는 도구입니다.
폰에는 앱 설치 없이 브라우저만 쓰고, PC에서 작은 파이썬 프로그램 하나만 실행하면 됩니다.

폰에서 접속하면 메뉴가 뜨고 둘 중 고릅니다:
- **🖥️ 화면 보기** — PC 화면을 폰에서 실시간으로 (보기 전용)
- **📁 파일 열람** — 지정한 폴더의 파일을 폰에서 미리보기만 (다운로드 없이)

> 단계별로 만드는 중이에요.
> - ✅ 화면 미러링 (보기)
> - ✅ 파일 열람 (미리보기 전용)
> - ✅ 마우스 (탭=클릭·드래그·스크롤·우클릭)  ← `pip install pyautogui` 필요
> - ⏳ 키보드 (한글 타이핑·단축키·볼륨/발표 키)

---

## 준비물
- PC와 폰이 **같은 와이파이**에 연결.
- PC에 **Python** 설치. (`python --version` 확인)
- 기능별 라이브러리 설치(필요한 것만):
  ```
  pip install mss pillow     # 화면 보기(미러링)
  pip install pyautogui      # 마우스 조작
  ```
  (파일 열람만 쓸 거면 설치 불필요 — 파이썬 기본 기능만 사용)

## 실행 (PC에서)
`pc_remote.py` 가 있는 폴더에서:
```
python pc_remote.py
```
- **파일로 열어줄 폴더**는 기본값이 바탕화면이에요. 다른 폴더로 하려면:
  ```
  python pc_remote.py --root "D:\공유폴더"
  ```
- 실행하면 접속 주소와 PIN이 뜹니다:
  ```
  ========================================================
    브로가드 PC 리모컨
  ========================================================
    폰/태블릿 브라우저에서 아래 주소를 여세요:
        http://192.168.0.12:8787
    PIN:  3741
    화면: 실제 캡처  1920x1080
    파일 폴더:  C:\Users\나\Desktop
  ========================================================
  ```
- 처음 실행 시 **Windows 방화벽 창**이 뜨면 **"액세스 허용"**(개인 네트워크)을 눌러주세요.

## 폰에서 접속
1. 폰 브라우저 주소창에 위 주소 입력: 예) `http://192.168.0.12:8787`
2. **PIN** 입력 → 메뉴에서 **화면 보기** 또는 **파일 열람** 선택.

### 화면 보기 + 마우스 조작
- PC 화면이 실시간으로 보입니다. 가로로 돌리거나 **전체화면** 추천.
- **화질**(낮음/보통/높음), **다시 연결** 버튼.
- **마우스 조작** (PC에 `pip install pyautogui` 설치 시 활성화):
  - **화면을 탭** = 그 위치를 **클릭**
  - **끌기** = 커서 이동 / **두 손가락으로 위아래** = 스크롤
  - **우클릭 / 더블클릭** 버튼 → 누른 뒤 원하는 곳을 탭
  - **✋ 드래그** 버튼 ON → 끌어서 이동·선택(드래그 앤 드롭)
  - **▲▼ 스크롤** 버튼
- pyautogui가 없으면 마우스 버튼이 숨고 **보기 전용**으로 동작해요.
  - 설치: `pip install pyautogui`  (윈도우는 보통 바로 됩니다)

### 파일 열람 (다운로드 없이 미리보기)
- 지정한 폴더 안을 폴더↔파일로 둘러봅니다. (지정 폴더 **밖으로는 못 나감**)
- 파일을 누르면 바로 미리보기: **이미지 · 동영상 · 음악 · PDF · 텍스트/코드**.
- 동영상은 폰으로 **직접 스트리밍 재생**됩니다(소리 O, 앞뒤 감기 O). PC에서 재생되는 게 아니라 폰이 재생해요.
- 폰에 **저장하지 않고 보기만** 합니다. (다운로드 버튼 없음)
  - 솔직히: 브라우저는 보여주려면 데이터를 받아와요. 그래서 '다운로드 버튼을 두지 않는' 방식이지, 작정하고 저장하는 것(이미지 길게 눌러 저장 등)까지 100% 막지는 못합니다.

### 변환 재생 (mkv·avi·HEVC 등 폰이 못 여는 동영상) — ffmpeg 필요(선택)
- 폰 브라우저가 못 여는 형식은 PC가 **실시간 변환(H.264/AAC)** 해서 보냅니다.
- 못 여는 동영상을 누르면 **자동으로 변환 재생**으로 전환되고, 수동 **⚙️ 변환** 버튼도 있어요.
- 쓰려면 PC에 **ffmpeg**가 있어야 합니다:
  - 윈도우: <https://www.gyan.dev/ffmpeg/builds/> 에서 받아 압축 풀고, `ffmpeg.exe`를 PATH에 넣거나
    `python pc_remote.py --ffmpeg "C:\ffmpeg\bin\ffmpeg.exe"` 처럼 경로 지정.
  - ffmpeg가 없으면 변환 기능만 조용히 꺼지고, 나머지(일반 재생·이미지·문서)는 그대로 됩니다.
- 변환은 PC CPU를 좀 씁니다. 되감기(탐색)는 변환 재생에선 제한될 수 있어요.

## 종료
PC 터미널에서 **Ctrl + C**.

---

## 실행 옵션
```
python pc_remote.py --root "D:\공유"   # 파일로 열어줄 폴더(이 폴더 밖은 접근 불가)
python pc_remote.py --port 9000       # 포트 변경 (기본 8787)
python pc_remote.py --pin 2580        # PIN 직접 지정
python pc_remote.py --no-pin          # PIN 없이 (집 네트워크 신뢰 시)
python pc_remote.py --fps 15          # 화면 초당 프레임 (기본 12)
python pc_remote.py --ffmpeg PATH     # ffmpeg 경로 지정(변환 재생용)
python pc_remote.py --demo            # 화면을 가짜(데모)로 — 설치 없이 테스트
```

## 자주 겪는 문제
| 증상 | 해결 |
|---|---|
| 폰에서 주소가 안 열림 | PC·폰 **같은 와이파이** 확인. 방화벽 **액세스 허용** 확인. |
| "PIN이 틀렸거나 연결 안 됨" | PC 터미널의 PIN·주소(포트 `:8787`)를 다시 확인. |
| 화면이 느림/끊김 | 화질 **낮음**, 또는 `--fps 8` |
| 화면 기능이 "꺼짐"으로 뜸 | `pip install mss pillow` 후 다시 실행. (파일 열람은 그래도 됨) |
| 포트 사용 중 | `--port 9000` 등 다른 포트 |

## 보안 메모
- **같은 와이파이 안에서만** 접속되도록 만들었습니다. 공용/회사 와이파이에선 PIN을 꼭 쓰고 끝나면 창을 닫으세요.
- 파일은 **지정 폴더 밖으로 못 나가게**(경로 탈출 차단) 막았습니다. 민감한 폴더는 `--root`로 피하세요.
- 집 밖에서 쓰려면 나중에 Tailscale 같은 걸로 안전하게 확장할 수 있어요.
