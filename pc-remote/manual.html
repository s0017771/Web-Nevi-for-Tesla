이게 뭐죠? 준비물 쉬운 설치 폰에서 접속 사용법 추가 설정 문제 해결

?이게 뭔가요?

폰/태블릿 브라우저에서 같은 와이파이에 연결된 Windows PC를 다루는 도구예요. 폰엔 앱 설치가 필요 없고(브라우저만), PC에서 작은 프로그램 하나만 켜두면 됩니다.

📱 폰/태블릿 (브라우저)
│    같은 와이파이    ▼
💻 PC에서 켜둔 작은 프로그램 → 실제 화면·마우스·키보드

폰에서 접속하면 [화면 보기] / [파일 열람] 메뉴가 나오고, 화면 보기에선 터치로 마우스·키보드까지 조작해요.

1준비물

  • PC와 폰이 같은 와이파이에 연결되어 있을 것
  • PC에 Python 설치 (없으면 python.org에서 설치 — 설치 중 "Add Python to PATH" 꼭 체크!)

나머지 구성요소(mss·pillow·pyautogui)는 아래 "쉬운 설치"가 자동으로 깔아줘요.

2쉬운 설치 (추천) 더블클릭 한 번

1
아래 두 파일을 같은 폴더에 내려받으세요. (예: 바탕화면에 새 폴더 하나)
▶️pc-remote.bat이걸 더블클릭해서 실행 🐍pc_remote.py리모컨 본체

위 버튼이 안 받아지면 GitHub에서 → pc-remote 폴더 에서 두 파일을 받으세요.

2
pc-remote.bat 를 더블클릭하세요. 처음엔 필요한 구성요소를 자동으로 설치한 뒤 리모컨이 켜져요.
실행하면 Windows 방화벽 창이 뜰 수 있어요 → "액세스 허용"(개인 네트워크)을 눌러야 폰이 접속됩니다.
3
검은 창에 접속 주소와 PIN이 나와요. 이걸 폰에서 쓰면 끝! 
  폰/태블릿 브라우저에서 아래 주소를 여세요:
      http://192.168.0.12:8787
  PIN:  3741
💡 다음부터도 pc-remote.bat 더블클릭이면 바로 켜져요. (이미 설치된 건 건너뜀)

폰에서 볼 폴더를 바꾸고 싶다면

pc-remote.bat를 메모장으로 열어 윗부분 한 줄만 고치면 돼요:

set "ROOT=%USERPROFILE%\Desktop"     ← 이 폴더를
set "ROOT=D:\공유폴더"                 ← 원하는 폴더로

수동으로 하고 싶다면 (대안)

명령 프롬프트(cmd)에서:

pip install mss pillow pyautogui
python pc_remote.py --root "D:\공유폴더"

3폰에서 접속

  1. 폰 브라우저 주소창에 PC 창에 뜬 주소 입력 — 예) http://192.168.0.12:8787
  2. PIN 입력 → 접속 (한 번 넣으면 기억돼요)
  3. 메뉴에서 화면 보기 또는 파일 열람 선택
📌 화면 보기는 PC가 가로라서, 폰을 가로로 돌리거나 전체화면 버튼을 쓰면 훨씬 커요.

4기능별 사용법

동작결과
화면을 탭그 위치를 클릭

마우스·키보드 기능은 PC에 pyautogui가 있을 때 켜져요(쉬운 설치가 자동으로 깔아줌). 없으면 보기 전용.

⌨️ 키보드

⌨️ 키보드 버튼 → 패널이 열려요.

  • 입력칸에 글자 → 전송 : PC에 타이핑 (한글 OK)
  • Enter · ⌫ · Space · Tab · Esc · 방향키
  • 단축키 : Win · Ctrl+C/V/Z/A · Alt+Tab · F5
  • 미디어/발표 : 🔊 볼륨± · 🔇 음소거 · ⏯ 재생 · 발표◀ / 발표▶(슬라이드 넘기기)
한글 전송은 붙여넣기 방식이라 PC 클립보드를 덮어써요. 영문/숫자는 그대로 타이핑됩니다.

📁 파일 열람 (다운로드 없이 미리보기)

  • 지정한 폴더 안을 둘러보고, 파일을 누르면 바로 미리보기: 이미지·동영상·음악·PDF·텍스트
  • 동영상은 폰에서 바로 재생돼요 (소리 O, 앞뒤 감기 O)
  • 폰에 저장하지 않고 보기만 합니다 (다운로드 버튼 없음)
  • 지정 폴더 밖으로는 못 나가요 (안전)

🎬 동영상 변환 재생 ffmpeg 필요(선택)

폰이 못 여는 형식(mkv·avi·wmv·HEVC 등)은 PC가 실시간 변환해서 보여줘요. 그런 영상을 누르면 자동으로 변환 재생으로 바뀌고, ⚙️ 변환 버튼도 있어요.

쓰려면 PC에 ffmpeg가 필요해요 — 여기서 받아 ffmpeg.exe를 PATH에 넣거나 --ffmpeg "경로" 옵션. 없어도 일반 영상은 그대로 재생돼요.

5추가 설정 · 옵션

옵션설명
--root "D:\폴더"파일로 열어줄 폴더(이 폴더 밖은 접근 불가)
--port 9000포트 변경(기본 8787)
--pin 2580PIN 직접 지정
--no-pinPIN 없이 (믿는 집 네트워크만)
--fps 8화면 초당 프레임(느릴 때 낮추기)
--ffmpeg "경로"ffmpeg 위치 지정(변환 재생)

cmd에서 예) python pc_remote.py --root "D:\공유" --port 9000

6자주 겪는 문제

증상해결
폰에서 주소가 안 열림PC·폰이 같은 와이파이인지 확인. 방화벽에서 "액세스 허용" 눌렀는지 확인.
"PIN이 틀렸거나 연결 안 됨"PC 창의 PIN과 주소(포트 :8787까지) 다시 확인.
화면이 느리거나 끊김화질을 낮음으로. 또는 --fps 8 로 실행.
마우스·키보드가 안 보임PC에 pip install pyautogui 후 다시 실행. (쉬운 설치면 자동)
"파이썬이 없어요"python.org에서 설치, "Add Python to PATH" 체크 후 bat 다시 실행.
동영상이 안 열림mp4가 아니면 ⚙️ 변환 눌러보기. (ffmpeg 설치 필요)
포트가 이미 사용 중--port 9000 처럼 다른 포트로.

🔒 보안 · 종료

  • 같은 와이파이 안에서만 접속되게 만들었어요. 공용/회사 와이파이에선 PIN을 꼭 쓰고 끝나면 창을 닫으세요.
  • 파일은 지정한 폴더 밖으로 못 나갑니다. 민감한 폴더는 --root로 피하세요.
  • 종료: PC의 검은 창에서 Ctrl + C.
  • 집 밖에서도 쓰고 싶다면 나중에 Tailscale 같은 걸로 안전하게 확장할 수 있어요.
